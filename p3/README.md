# Funcionalidades añadidas/implementadas

- Se ha ampliado la escena a un sistema solar completo: sol y los ocho planetas (Mercurio, Venus, Tierra, Marte, Júpiter, Saturno, Urano y Neptuno), cada uno con su propio radio de órbita, velocidad de traslación y color.
- Se han añadido lunas a varios planetas (Tierra, Marte, Júpiter y Saturno).
- Se ha sustituido el dibujado por cuadrados por puntos y que se vean circulares tanto el sol, los planetas y las lunas.

# Teclas y acciones para manejar la demo

- Los planetas y lunas se mueven de forma automática en cada frame sin necesidad de ninguna tecla para iniciar o pausar el movimiento.
