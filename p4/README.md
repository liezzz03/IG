# Funcionalidades añadidas/implementadas

- Laberinto generado a partir de un mapa de tecto, con paredes de cubos y suelo en rejilla.
- Cámara en primera persona con giro.
- Movimiento con incercia: aceleración, rozamiento, velocidad máxima y derrape al girar.
- Colisiones con las paredes.
- Modo vuelo donde se puede subir y bajar, y sobrevolar las paredes.
- Enemigos que persiguen al jugador esquivando las paredes, reaparecen en puntos alejados.
- Disparo con balas que chocan con paredes y enemigos.

# Teclas y acciones para manejar la demo

- WASD y flechas para manejar al jugador.
- Con el ratón (click izquierdo y arrastrar sobre el canvas) se puede mirar alrededor y girar.
- Espacio (mantener) para disparar en ráfaga.
- F para alternar entre modo vuelo o suelo. Asimismo, EQ para subir/bajar mientras se vuela.
