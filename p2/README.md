# Funcionalidades añadidas/implementadas

- Se han creado funciones para que la pelota rebote cuando 'toque' las barras, y, dependiendo de donde golpee, la bola rebote con un ángulo u otro, y con una velocidad u otra.
- Se ha implementado un conteo de puntos para que cuando llegue a X puntos la partida termine y se anuncie el jugador que ha ganado.

# Teclas y acciones para manejar la demo

- Teclas W/S para subir/bajar la barra del jugador uno. (Barra de la izquierda)
- Teclas de las flechas para subir/bajar la barra del jugador dos. (Barra de la derecha)
- Tecla R para reiniciar la partida.
